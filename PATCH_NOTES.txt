PublicVideoLauncher patch notes

Changes applied:
1. Fast failure when cloudflared exits before a public URL is produced.
2. Optional selected-video startup restored for the GUI:
   - if a video is selected in the list, the generated public URL starts with that file.
3. Public URL is copied to clipboard automatically after successful start.
4. Clear log message when requested port is busy and a fallback port is used.
5. Safer temporary asset download naming for cloudflared downloads.

Notes:
- This environment did not include the .NET SDK, so the patch is based on static code inspection rather than a local build.
- The player currently writes translateSrc/originalSrc metadata into playlist.json, but player.html still plays src only.
